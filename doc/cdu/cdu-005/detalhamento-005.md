# CDU005. Visualizar Projetos Similares
- **Ator principal**: Todos (Visitante, Comum, Orientado e Orientador)
- **Atores secundários**: Nenhum	 
- **Resumo**: Este caso descreve os passos para que o usuário acesse a visualização de projetos similares no sistema.
- **Pré-condição**: Listar o projeto via mecanismos de busca e projeto existir no banco de dados. 
- **Pós-Condição**: O sistema apresenta a interface gráfica dos dados do projeto similares.

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :---: | :---: | 
| 1 - O usuário seleciona um projeto via busca, recomendações (mais avaliados) ou perfil. | |  
| | 2 - O sistema redireciona o usuário para página do projeto e projetos similares.|
